# План реализации P0/P1 ТИИм Pulse

Цель: устранить подтвержденные дефекты границ данных и импорта, подготовить воспроизводимый контрольный набор для независимой оценки качества.

Основание: [технический аудит](../../cases/ai-agent/audit-2026-11-05.md) и требования к P0/P1. Архитектура: существующие модули и отдельный офлайн-пакет `mvp/dataset`; без новых runtime-зависимостей генератора. Исполнение последовательно в отдельной ветке.

## Ограничения

- Все описания на русском, в инженерном стиле для конкурсной работы.
- Внешние модели и корпоративные данные не используются.
- Gold, workflow, intent, security-метки и ожидаемое поведение не передаются модели.
- Holdout не используется для выбора порогов; эталоны не вычисляются текущим классификатором.
- Общие issue-семейства, включая разные продукты и версии, принадлежат одной выборке.

## Проверяемые пограничные случаи

Redirect POST и proxy; неравное пересечение с двумя подтвержденными сигналами; чувствительный ввод в 422; два одиночных файла и отказ провайдера; поврежденный датасет, измененные метки, пересечение семейств, повторные события и неоднозначное многопроблемное обращение.

Файлы: `mvp/ollama_embeddings.py`, `cluster_identity.py`, `service.py`, `api.py` и соответствующие тесты.

## Задача 2 — P1

Создать `mvp/dataset/{catalog,generator,validation,__main__}.py`, тесты `test_dataset.py`, инструкцию и контрольный набор `mvp/datasets/pulse-synthetic-v1/`.

Контракт: `generate_dataset(size=500, seed=20261105)` возвращает раздельные признаки, эталоны и события по выборкам; `validate_dataset(bundle)` отклоняет нарушенные инварианты; `write_dataset(bundle, output)` создает файлы с манифестом и SHA-256. CLI `python -m dataset generate --size 500 --seed 20261105 --output PATH`, `python -m dataset validate --directory PATH`.

- [ ] Проверить отсутствие пакета тестами, затем реализовать сценарии и генератор.
- [ ] Обеспечить все 15 классов случаев, независимую разметку и изоляцию семейств.
- [ ] Добавить версии/повторы событий и слепую экспертную выборку.
- [ ] Проверить побайтовую воспроизводимость, обнаружение повреждений, отсутствие утечки и размеры 500/1 000/5 000/10 000.
- [ ] Сохранить контрольный набор, обновить README и CI, выполнить полный unittest и проверки зависимостей/секретов.
- [ ] Создать commit и PR, проверить CI, выполнить итоговый review и объединить при успешных проверках и отсутствии блокирующих замечаний.
