# Как докажем эффект Маржрута: проект A/B-пилота

## Что действительно измерено

В исходном XLSB доступны месячные объемы заправок и относительные цены за сентябрь 2023 — май 2024 года. Для 6 715 клиентов правила классификации дают высокий **наблюдаемый сигнал**; у 4 050 из них в историческом справочнике есть приложение и согласие на push. Это *не* подтвержденная ценозависимость и *не* список для немедленной рассылки.

При дополнительной **локальной** проверке исходной книги (не публикуем строки клиентов) у этих 4 050 клиентов стандартное отклонение **индивидуального среднего месячного объема за март—май 2024** составило около **50,71 л**. Это всего лишь ориентир для предварительного расчета мощности: будущая дисперсия после рандомизации неизвестна, состав аудитории изменится, в исторических данных есть сезонный тренд.

## Ключевое решение: два разных пилота

1. **Технический пилот (~10% от 4 050, около 405 клиентов):** проверить доставку, право на коммуникацию, корректность бонуса, контроль отписок, сохранение контрольной группы и полноту учета. По 202–203 клиента на группу **не хватает** для надежного подтверждения малого эффекта. Не использовать как успешное доказательство 3 л uplift.
2. **Подтверждающий эксперимент:** отдельно определить первичный KPI, длительность наблюдения, итоговую выборку и критерии успеха. Нельзя объявлять подтвержденным результат только потому, что среднее treatment выше control или оценка сценарной прибыли положительна.

## Проверяемая арифметика мощности

При независимых клиентах, общей SD `σ`, двустороннем уровне значимости `α`, мощности `1−β` и размерах групп `n_T`, `n_C` используется приближенный минимум различимого эффекта:

`MDE ≈ (z_(1−α/2) + z_(1−β)) × σ × sqrt(1/n_T + 1/n_C)`.

Для `α=0,05`, мощности `80%`, `σ=50,71 л`, **без** гипотетических скидок на дисперсию:

| Размер пилота | Участников в группах | Минимальный различимый эффект |
| --- | ---: | ---: |
| Техническая проверка 10% | 202 и 203 | **≈14,12 л** на клиента |
| Теоретически все 4 050 | 2 025 и 2 025 | **≈4,46 л** на клиента |
| Цель различить 3 л | **≈4 486 на каждую группу** | Недостаточно клиентов в данном сегменте |

Последняя строка — расчет необходимой выборки, а **не** реально доступная аудитория. Ориентир SD получен по среднему трех месяцев, а результат 30-дневного эксперимента может иметь иную дисперсию. Если говорить о более шумном одном месяце, требуемая выборка может быть еще выше. Разделение по станциям/стратам и кластерная зависимость также могут ухудшить точность. Статистическая мощность и экономическая безубыточность — разные задачи.

Историческая проверка связи «среднее января—марта → среднее апреля—мая» в этой подгруппе дает `R² ≈ 0,153`. Это лишь исследовательская диагностика и **не подтвержденная** экономия дисперсии для будущего пилота. Поэтому калькулятор по умолчанию не учитывает поправку ковариатами. Можно смоделировать потенциальную пользу корректировки, но нельзя обещать ее заранее.

## Первичный показатель и правила

**Первичный KPI:** разность среднего объема литров, купленных в сети за заранее фиксированные 30 дней после назначения группы, в пересчете на **всех рандомизированных** клиентов (ITT). Клиентов, не открывших push или не совершивших заправку, исключать нельзя. Клиент с нулем литров внутри сети мог перейти к конкуренту, но такие покупки нам неизвестны; это не прямой показатель ухода к конкуренту.

**Экономический KPI:** разность среднего фактического вклада (маржа по проданному топливу минус реально начисленные бонусы и коммуникационные издержки) между группами. Финансовая трактовка `Маржа` и включенность OPEX должны быть подтверждены до объявления ROI.

**Ограничения эксперимента:**

- Перепроверить актуальное согласие, карту и приложение непосредственно перед коммуникацией. Контролю не показывать предложение.
- Назначать группы один раз до кампании; фиксировать версию правила, период, исходы, правила исключения и все первичные метрики.
- Стратифицировать по АЗС × топливо либо региону × топливо; при перекрестных посещениях возможна интерференция и требуется проверка выбора единицы рандомизации.
- Сравнить базовые показатели между ветками: предшествующий объем, тип АЗС, топливо, регион. Приблизительно равный размер групп **не гарантирует** баланс.
- Выводить разницу ITT и доверительный интервал с учетом стратификации/кластеризации; контроль множественных сравнений для дополнительных сегментов.
- Останавливать кампанию при ошибочном начислении, нарушении согласий, существенных жалобах и выходе за маркетинговый бюджет; не делать незапланированных проверок значимости с ранней остановкой «на победе».
- Для масштаба требовать положительного **инкрементального** эффекта с учетом стоимости бонусов. Технический пилот может быть успешен по техническим критериям, но не по марже.

## Воспроизведение сценарной мощности

Из каталога `cases/retail-marketing` (стандартная библиотека Python):

```bash
python src/power.py
python src/power.py --eligible 4050 --sample-share 1 --baseline-sd-liters 50.71 --target-effect-liters 3
python src/power.py --eligible 4050 --sample-share 1 --baseline-sd-liters 50.71 --target-effect-liters 5 --variance-reduction 0.15
```

`variance-reduction` — **пользовательское предположение**, а не достигнутый результат. Вывод содержит `MDE`, полуширину доверительного интервала, рекомендуемое количество участников и флаг доступности выборки. Ни один расчет мощности не подменяет фактический результат A/B.
