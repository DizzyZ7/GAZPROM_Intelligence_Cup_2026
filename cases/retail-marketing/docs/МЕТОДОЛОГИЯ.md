# Методология «Маржрута»

## Точная постановка

Организатор просит выявить клиентов с чувствительностью к **изменению ценового положения** АЗС по отношению к соседним конкурентам, выделить сегменты, проверить устойчивость и обозначить ограничения. В источнике помесячные объемы и цены, поэтому исследование носит ретроспективный наблюдательный характер.

### Данные и единицы

- Наблюдение: клиент *i*, АЗС *s*, вид топлива *f*, месяц *t*.
- `V_it` — суммарный объем купленного топлива за месяц, литров, включая нулевые месяцы.
- `P^G_sft`, `P^C_sft` — средняя цена сети и конкурентов, руб./л.
- `G_sft = P^G_sft − P^C_sft`. Положительное значение — сеть дороже.
- Регион, тип станции и формат — справочник АЗС. Наличие приложения и согласие на push — отдельный справочник клиентов.
- Исторический период 09.2023–05.2024. Нет данных о конкурентной цене на конкретный день или времени принятия решения.

### Почему нельзя использовать корреляцию по всем строкам

Помесячная агрегированная корреляция между средним ценовым разрывом и средним клиентским объемом равна примерно **−0,942**. Но это корреляция всего по **9 точкам**. Общая сезонность, активность клиентской базы и тренды цен могут одновременно влиять на обе величины. Кроме того, цена общая для всех клиентов одной пары АЗС × топливо × месяц: записи клиентов **не являются независимыми ценовыми экспериментами**.

### Выбранный показатель — относительный поведенческий индекс

Чтобы хотя бы частично вычесть общие события на одной АЗС, создаем для клиента базовую линию — медиану `log(1+V)` *других* клиентов той же АЗС, того же топлива, в тот же месяц:

`R_it = log(1+V_it) − median_{j ≠ i, s_j=s_i, f_j=f_i} log(1+V_jt)`.

Этот шаг технически выполнен как **leave-one-out**: клиент не входит в свой эталон.

Для каждого клиента центрируем по времени девять значений `G_it` и `R_it`, далее считаем регуляризованный наклон:

`S_i = sum_t[(G_it − mean(G_i)) * (R_it − mean(R_i))] / (sum_t[(G_it − mean(G_i))²] + 4)`.

Параметр `+4` сглаживает нестабильные наклоны при малом числе наблюдений. Индекс имеет приближенные единицы изменения логарифма относительного объема на руб./л, **не является классической ценовой эластичностью, причинным эффектом или оценкой вероятности оттока**. Сравнение с соседями той же АЗС может скрыть общую реакцию всего потока клиентов.

### Фильтры качества

Сегментируем только если:

- в группе АЗС × топливо есть хотя бы 8 клиентов;
- клиент покупал топливо минимум в 6 из 9 месяцев;
- купил не менее 200 литров за все 9 месяцев;
- его ценовой разрыв изменился минимум на 1 руб./л.

Иначе — `Недостаточно данных`. Значение индекса может быть рассчитано технически, но не считается основанием для отбора.

### Сегменты (исследовательские пороги)

| Сегмент | Правило | Обращение |
|---|---|---|
| Высокий наблюдаемый сигнал | `S_i ≤ −0,08` | Проверять в ограниченном пилоте |
| Умеренный наблюдаемый сигнал | `−0,08 < S_i ≤ −0,025` | Отдельная тестовая страта |
| Сигнал не выявлен | `S_i > −0,025` | Не давать скидку по ценовому основанию без других фактов |
| Недостаточно данных | Не прошел фильтры | Не классифицировать как чувствительного |

Пороги — **предварительный экспертный выбор**, не оптимизация по `holdout`, не основание считать сегменты ground truth.

### Проверка устойчивости

Считаем индекс отдельно на первых шести (09.2023–02.2024) и последних трех (03–05.2024) месяцах. Сравниваем знак у тех, кто имеет достаточную вариацию разрыва (`≥0,5` руб./л в первых шести, `≥0,25` руб./л в последних трех) и прошел общие фильтры. Совпадение знака — около **49,2%**. Выборка ~17,6 тыс. пригодных для такой проверочной процедуры.

Это **не подтверждает устойчивое индивидуальное прогнозирование**. Следствие: не делать утверждений «мы точно нашли 6715 ценозависимых». Говорить «выделили 6715 кандидатов по слабому поведенческому сигналу; тестируем гипотезы».

### Что улучшить после конкурса

1. 12–24 месяцев истории и дневные цены, в том числе промоакции, чеки, типы заправок, события по карте, сезонные факторы, цена в доступных клиенту станциях.
2. Идентификация на изменениях цен между территориями / естественных экспериментах с проверкой параллельных трендов.
3. Сегменты с доверительными интервалами и калибровкой на holdout/внешнем периоде.
4. Causal uplift-модель на результатах рандомизированного пилота, а не на необоснованных корреляциях.
5. Мониторинг распределений, динамики, справедливости, потери маржи и разрешений на сообщения.

## Проверки данных

- 33 146 уникальных клиентских ID в расчетной таблице.
- 642 АЗС из 1655 в полном справочнике.
- Для 7 клиентов нет строки справочника клиентов.
- Для 12 830 клиентов нет строки в справочнике сопутствующих покупок. Это **не доказанный ноль покупок**; не используем как `0` без отдельной политики пропусков.
- Данные по марже/плотности покрывают расчетные сочетания топлива и региона. Не переносить региональную маржу на другие рынки без проверки единиц и учетной методики.

## Ограничения и безопасность

- Нет подтвержденных фактов выбора конкурентной АЗС: ноль покупок в сети не означает покупку у конкурента.
- Отсутствуют расстояния до конкурентов и фактический радиус 2 км, это контекст из постановки.
- Согласие на маркетинговый push должно быть актуальным на момент отправки, а не только историческим.
- Не экспортировать персональные идентификаторы в презентацию и демо; расчет выполняется локально, без сторонних сервисов.
