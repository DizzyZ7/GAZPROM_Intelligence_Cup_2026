# Устойчивость сегментации и стресс-тест бонусов

> Анализ на предоставленной организаторами книге XLSB. Не является оценкой причинной эластичности или результатов рекламной кампании.

## Что проверили

Базовая сегментация использует два порога относительного индекса: **−0,08** (высокий сигнал) и **−0,025** (умеренный). Мы одновременно изменили абсолютную величину обоих отрицательных порогов на ±20% без переобучения индексов и без изменения условий допуска (8 клиентов на АЗС × топливо, 6 активных месяцев, 200 л, диапазон разрыва 1 руб./л).

| Сценарий | Высокий сигнал | Умеренный сигнал | Всего кандидатов | Исторически доступно для push | Изменили конкретный сегмент |
| --- | ---: | ---: | ---: | ---: | ---: |
| мягче на 20% | 7049 | 1165 | 8214 | 4910 | 491 |
| базовый | 6715 | 1342 | 8057 | 4823 | 0 |
| строже на 20% | 6426 | 1486 | 7912 | 4743 | 434 |

Количество кандидатов меняется на **+1,95%** при смягчении и **−1,80%** при ужесточении относительно базовых 8 057. При этом часть клиентов переходит между соседними сегментами: *устойчивость суммарного размера аудитории не равна устойчивости индивидуальных назначений*. Отдельная проверка разделением по времени дала только **49,2%** согласования направления сигнала — это сильное ограничение применимости.

Из-за этого нельзя предлагать массовый бонус исходя из принадлежности к сегменту: кандидат проходит проверку актуального согласия и рандомизированный эксперимент, после которого решение принимается по реальному приросту и чистой марже.

## Сценарный стресс-тест экономики

Использованы исключительно **проектные допущения**: маржинальный вклад **9,94 руб./л** (для примера, зависит от определения маржи и OPEX), чек **40 л**, вероятность применения бонуса **40%**, коммуникация **0,10 руб./назначенного участника**. Стоимость бонуса учитывается на *весь чек*, а не только на инкрементальные литры.

| Бонус, руб./л | Ожидаемая стоимость бонуса, руб./уч. | Безубыточность, дополнительных л/уч. | Результат при 1 доп. л, руб./уч. | Результат при 3 доп. л, руб./уч. |
| ---: | ---: | ---: | ---: | ---: |
| 0.30 | 4.80 | 0.493 | +5.04 | +24.92 |
| 0.50 | 8.00 | 0.815 | +1.84 | +21.72 |
| 1.00 | 16.00 | 1.620 | -6.16 | +13.72 |

Сценарный результат — **ожидаемый добавочный вклад на участника тестовой группы при заданном гипотетическом uplift**, а не реально измеренная прибыль. При нулевом uplift все три бонуса убыточны. Технический пилот не доказывает эффекта 1–3 л, а для масштабирования необходимо подтвердить и увеличение объема, и положительный инкрементальный вклад относительно контрольной группы.

Важные ограничения: исторические согласия не гарантируют разрешения на текущую коммуникацию; исходные данные не содержат реальных кампаний и погашений бонусов; маржа и OPEX могут частично дублироваться; сравнение по одной АЗС может скрыть общую реакцию всех клиентов на изменение цены.

## Воспроизведение

Из каталога `cases/retail-marketing`:

```bash
python src/analyze.py --input "/путь/к/Кейс_Ретейл и маркетинг_Дополнительные данные.xlsb" --output outputs
python src/sensitivity.py
python -m unittest discover -s tests -v
```

Первая команда формирует `outputs/sensitivity.json` на реальных исторических данных — без экспорта клиентских ID. Вторая печатает таблицу сценарной экономики без доступа к XLSB. Данные полностью локальны, внешние сервисы не вызываются.

Исходные агрегаты и формулы доступны в [metrics.json](../outputs/metrics.json), [sensitivity.json](../outputs/sensitivity.json), [analyze.py](../src/analyze.py), [sensitivity.py](../src/sensitivity.py), [economics.py](../src/economics.py).
