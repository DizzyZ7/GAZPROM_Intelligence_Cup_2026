# Экономика, маржа и дизайн пилота

## Фактические поля из XLSB

В листе `Маржа` есть средняя маржа и средний OPEX по региону и виду топлива в руб./т; в `Плотность` — физическая плотность в кг/л. Примерное превращение в руб./л:

`c = (средняя маржа руб./т − OPEX руб./т) × плотность кг/л / 1000`.

**Ограничение учета:** не подтверждено, учитывает ли показатель «Средняя маржа» операционные расходы. Если он уже net of OPEX, вычитание второй раз ошибочно. Перед коммерческим применением потребуется согласование с финансистами.

Для сегмента с высоким сигналом и согласием на push среднее расчетное `c ≈ 9,94 руб./л`. Исторический объем — около 89,96 л/клиент/месяц. Это оценки из конкурсного файла, а не выручка или подтвержденная валовая прибыль.

## Юнит-экономика оффера

Пусть:
- `U` — **инкрементальные литры на одного рандомизированного клиента treatment**, еще не измерены;
- `c` — вклад руб./л;
- `r` — доля погасивших предложение;
- `L` — оплачиваемые скидкой литры за погашение;
- `d` — скидка руб./л;
- `k` — коммуникационные расходы на одного treatment.

Тогда ожидаемый эффект на клиента treatment:

`Net = U*c − r*L*d − k`.

Точка безубыточности: `U_break_even=(r*L*d+k)/c`.

**ОЧЕНЬ ВАЖНО:** оплачиваемая скидка начисляется всем погасившим, в том числе тем, кто купил бы без бонуса; поэтому нельзя считать экономию только на «возвращенных» клиентах.

### Базовые сценарные параметры (не измерены)

| Параметр | Значение | Статус |
|---|---:|---|
| Сильный сигнал + приложение + push-согласие | 4 050 чел. | Из исходных данных и алгоритма |
| Доля выбранного сегмента для пилота | 10% | Предположение |
| Treatment / control | 50% / 50% | Экспериментальное предложение |
| Treatment после округления | 203 чел. | Расчет в Excel |
| `c`, руб./л | 9,94 | Из маржи/плотности с оговоркой OPEX |
| Доля погашений | 40% | Гипотеза |
| Покрытие предложения | 40 л/погашение | Гипотеза |
| Скидка | 0,50 руб./л | Гипотеза |
| Коммуникации | 0,10 руб./клиент treatment | Гипотеза |
| `U`, л на treatment | 1 / 3 / 5 | Консервативный / базовый / оптимистичный сценарии |

Для базовых допущений безубыточность около **0,815 л дополнительного объема на одного treatment**. Значение реалистично как арифметический порог, но вероятность достижения неизвестна.

Это пилотный расчет **не для всех 13,5 млн участников**. Механическое масштабирование по конкурсной выборке недопустимо.

## План A/B

1. Сформировать пилотную выборку, затем рандомизировать 50/50 в treatment/control. Стратифицировать по АЗС и виду топлива там, где хватает клиентов; малые группы объединить до более крупных страт (например, регион × топливо), чтобы обеспечить обе ветки теста.
2. Состав групп должен быть сбалансирован по станции, топливу, среднему объему и статусу карты. Один клиент должен входить в одну экспериментальную группу.
3. Период кампании и измерения задать до запуска, например 30 дней после рассылки, и зарегистрировать основные гипотезы.
4. Измерять *intention-to-treat*: все рандомизированные клиенты учитываются, даже если не открыли сообщение. Для стоимости — фактические бонусы и затраты.
5. Оценивать прирост литров и маржи treatment-control с интервалами неопределенности и кластерными стандартными ошибками по АЗС (либо рандомизация на уровне АЗС при ожидаемом spillover).
6. Дорастить выборку по power analysis до запуска. Нынешний небольшой пилот — концептуальная отправная точка; он **не гарантирует достаточную мощность**.
7. Стоп-условия: ухудшение валового вклада, рост отписок/жалоб, выход за бюджет, техническая ошибка начисления бонуса.

## Финансовая модель

`МАРЖРУТ_Экономическая_модель.xlsx` содержит редактируемые параметры (синим) и формулы для трех гипотетических значений `U`. Не заменять формулы итоговыми константами: именно чувствительность результата к параметрам важна для экспертов.
