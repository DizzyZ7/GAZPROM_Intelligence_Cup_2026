# ТИИм Pulse — тестирование и приемка v1

## Датасет
Разметить стратифицированную выборку обращений по продуктам, каналам, типам, периодам; исключить утечки между train/dev/test по связанным тикетам. Два эксперта размечают спорные случаи, фиксируют согласие и adjudication.

## Тесты
- Классификация: precision/recall/F1 по классам, confusion matrix.
- Кластеры: pairwise precision/recall, доля ложных объединений разных причин, ручной аудит крупных кластеров.
- Извлечение фактов: полнота evidence, отсутствие выдуманных фактов.
- ASR/VL: качество на реальных аудио и изображениях, fallback при плохом качестве.
- Security: prompt injection в тексте тикета, утечка ПДн, RBAC, cross-product isolation.
- Reliability: идемпотентность, повторы событий, пропущенные вложения, таймауты, DLQ, восстановление.
- Business: доля принятых продуктовых сигналов, время от обращения до рассмотрения, часы ручной аналитики.

## Предлагаемые release gates (не официальные требования)
Нулевые критические нарушения доступа/утечки на тестовом наборе; все сигналы проходят human review; качество классификации и кластеров выше согласованного baseline; доставка идемпотентна; измерены p95 задержки и затраты ресурсов. Числовые пороги определить по базовой линии и цене ошибок, не выдумывать.

## Этапы
Offline evaluation → shadow mode без отправки → ограниченный пилот с согласованием → решение о расширении.
