## Ограничения конкурса

По материалам репозитория внешние LLM/API запрещены; интерфейс внутренних Qwen/ASR/VL не предоставлен. Синтетические обращения позволяют проверить алгоритмы и отказоустойчивость, но не подтверждают качество на корпоративном потоке. Сведения о нагрузке, правах, источнике и целевом канале доставки не установлены. SQLite сохраняется для локального MVP.

## Решение для первой итерации

Сохраняются Python, FastAPI, SQLite, EmbeddingProvider и действующие API. P0 исправляется без изменения формата успешных ответов. P1 — отдельный офлайн-пакет на стандартной библиотеке: независимый каталог сценариев, генератор, структурный валидатор, раздельные файлы признаков/эталонов/событий и контрольные суммы. Новые версии событий генерируются для будущих проверок; текущий API их не применяет.

Альтернативы: размножение семи примеров не дает нужного разнообразия; генерация внешней моделью нарушает границы контура и снижает воспроизводимость. Каталог с несколькими независимыми формулировками и композиционными форматами дает проверяемый начальный набор, но сохраняет смещение синтетических данных и требует экспертной оценки.
