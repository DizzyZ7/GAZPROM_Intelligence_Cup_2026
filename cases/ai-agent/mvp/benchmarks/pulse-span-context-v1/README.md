# Выделение цитат и нормализация для поиска повторов

Офлайн-эксперимент проверяет два этапа отдельно. Qwen3.5:4b предлагает категорию и два фрагмента обезличенного обращения — операцию и наблюдаемый симптом или пожелание. Сервер восстанавливает границы в исходном для модели тексте и решает, можно ли использовать цитаты при поиске повторов.

## Схема сравнения

- Допускается различие регистра, если цитата однозначно указывает на один фрагмент. Для отчета и сопоставления берется дословный срез текста. Пересказ, обрезанное отрицание, пропущенный распознанный код ошибки, пересекающиеся цитаты и фрагменты из разных операций приводят к отказу.
- Один прогон модели дает общий набор проверенных фрагментов. Метод `literal` сравнивает срезы буквально. Метод `normalized` приводит русские слова к основам, нормализует пробелы и обрамляющую пунктуацию, сохраняет порядок слов, отрицания и числовые и латинские коды. Оба метода требуют совпадения продукта и категории. Третий метод — контекстные правила v2.3. [Алгоритм русской нормализации Snowball](https://snowballstem.org/algorithms/russian/stemmer.html).
- `diagnostic.json` отдельно показывает совпадение цитаты с эталоном до и после защитных проверок. Для попадания требуется символьный F1 не ниже 0,5 хотя бы с одной эталонной альтернативой. В знаменатель входят продуктовые обращения с обеими эталонными цитатами. `gold_quotes_only` сравнивает методы на первых эталонных цитатах как диагностику возможностей нормализации при размеченном входе.
- `evidence.json` связывает SHA-256 обезличенного текста, полуоткрытые символьные границы фрагментов и причину допуска или отказа. `comparison.csv` и каталоги методов содержат раздельные метрики категории, поиска пар и кластеров, примеры ошибок и замеры.
- Validation содержит те же 24 записи, что в эксперименте v1.1. Holdout содержит 36 новых синтетических обращений. Код, версии модели и нормализатора, параметры и входные манифесты зафиксированы до контроля. Эталоны читаются после формирования всех предсказаний. Holdout запускается после завершенного validation и резервируется квитанцией для выбранной фиксации. [Датасет](../../datasets/pulse-span-holdout-v1/README.md).
- Ollama работает на loopback с отключенным облаком, без инструментов и прокси. Путь эксперимента маскирует email, российские телефонные шаблоны и явно записанные последовательности со знаком `+` и минимум восемью цифрами. Диапазон допустимых форматов и правила выявления недоверенных инструкций ограничены. Синтетическая разметка ожидает доменной проверки человеком.

## Результаты

| Выборка | Метод | Верная категория | Macro F1 категории | Поиск TP / FP / FN | F1 поиска | Pairwise F1 кластеров |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| validation (24) | Правила v2.3 | 17/24 | 0,699 | 1 / 0 / 3 | 0,400 | 0,400 |
| validation (24) | Дословные цитаты | 14/24 | 0,580 | 0 / 0 / 4 | 0,000 | 0,000 |
| validation (24) | Нормализация Snowball | 14/24 | 0,580 | 0 / 0 / 4 | 0,000 | 0,000 |
| holdout (36) | Правила v2.3 | 10/36 | 0,169 | 0 / 0 / 11 | 0,000 | 0,000 |
| holdout (36) | Дословные цитаты | 14/36 | 0,344 | 0 / 0 / 11 | 0,000 | 0,000 |
| holdout (36) | Нормализация Snowball | 14/36 | 0,344 | 0 / 0 / 11 | 0,000 | 0,000 |

На validation в PR №8 сервер принял 1 контекст из 24. В этом прогоне он подтвердил наличие обеих цитат в 3 обращениях и допустил 2 контекста. Правила v2.3 нашли 1 из 4 эталонных пар. Оба варианта с цитатами нашли 0 из 4.

На holdout выполнено 33 вызовов модели. В 13 из 36 обращений обе цитаты привязаны к тексту, в 11 обращениях контекст допущен к сопоставлению. Среди 26 размеченных продуктовых обращений попадание по операции получено в 10 случаях, по симптому — в 17. Обе цитаты попали в эталон в 10 случаях, защитные проверки пропустили 9 из них.

На тех же цитатах буквальное сравнение дало 0 верных и 0 ложных пар, Snowball — 0 верных и 0 ложных. Диагностика с первыми эталонными цитатами дала 0 и 0 верных пар из 11 соответственно. Ложные пары в этой диагностике — 0 и 0.

У 5 из 11 пропущенных пар различались предсказанные категории. Еще 3 пары не дошли до сопоставления из-за воздержания, у 3 различались ключи операции. Равенство основ не помогло даже на эталонных цитатах. Следующий эксперимент должен проверять семантический поиск кандидатов по подтвержденным фрагментам с фильтрами по продукту, категории, коду и отрицанию.

Из 10 случаев обязательного воздержания к сопоставлению допущено 0. В отдельных пробах синтетические телефон и email скрыты до локального вызова. Оба обращения с подложными инструкциями остановлены перед моделью. Причины сохранены в `evidence.json`.

Извлечение на holdout заняло 232,8 с в последовательном CPU-прогоне. Ollama сообщил 3,08 ГБ загруженного состояния и 0 байт VRAM. [Условия запуска](runtime.json).

До запуска holdout обновили проверку многострочных телефонных записей, отрицаний и распознаваемых кодов ошибок. Validation повторен на зафиксированном после ревью коде. Выводы относятся к синтетическому набору и выбранной модели. Эксперимент остается офлайн.

Матрицы категорий, ошибки и доказательства доступны в каталогах методов. Таблицы сравнения — [validation](validation/comparison.csv) и [holdout](holdout/comparison.csv).

## Воспроизведение

Команды выполняются из `cases/ai-agent/mvp`. Используйте Python 3.11 или 3.12 и Ollama. Тег модели может измениться. Перед сравнением проверьте digest и версию Ollama по `frozen-config.json`.

```bash
python -m pip install -r requirements-dev.txt
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 OLLAMA_NUM_PARALLEL=1 ollama serve
```

В другой оболочке запустите проверку в новом каталоге.

```bash
ollama pull qwen3.5:4b
pulse_reference=datasets/pulse-synthetic-v1
pulse_holdout=datasets/pulse-span-holdout-v1
pulse_output=/tmp/pulse-span-reproduction
python -m span_eval freeze --reference "$pulse_reference" --holdout "$pulse_holdout" --output "$pulse_output"
python -m span_eval evaluate --split validation --reference "$pulse_reference" --holdout "$pulse_holdout" --output "$pulse_output"
python -m span_eval evaluate --split holdout --reference "$pulse_reference" --holdout "$pulse_holdout" --output "$pulse_output"
python -m span_eval verify --reference "$pulse_reference" --holdout "$pulse_holdout" --output "$pulse_output"
```

Контроль сохраненных файлов выполняется без запуска модели.

```bash
python -m span_eval verify \
  --reference datasets/pulse-synthetic-v1 \
  --holdout datasets/pulse-span-holdout-v1 \
  --output benchmarks/pulse-span-context-v1
```
