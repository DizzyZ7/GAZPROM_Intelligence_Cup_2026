# Слепая синтетическая выборка Pulse P3

В выборке 152 русскоязычных обращения для двух вымышленных продуктов, по 76 на каждый. Каналы: чат, электронная почта, веб-форма, отзыв в приложении, расшифровка звонка и форум. Названия продуктов, тексты и обстоятельства созданы для этого набора. Единственный адрес электронной почты использует домен `example.invalid`.

Выборку и эталон составил отдельный автор, который не участвовал в реализации анализатора P3. Базовый каталог `dataset/catalog.py` из ревизии `601db953c51ec60c17680f5c06e3f72e5c8feaa6` использован только для исключения повторов, в том числе редких случаев. При составлении не использовались код P3, предсказания, оценки качества или подобранные параметры. До фиксации кода и параметров анализатор на выборке не запускался.

- `holdout.inputs.json` — входы: идентификатор обращения, продукт, текст и канал. Идентификаторы обращений непрозрачны. Передавайте анализатору только этот файл.
- `holdout.labels.jsonl` — отдельный эталон, по одной строке на обращение. Связь с входом только по `ticket_id`; порядок строк не совпадает с порядком входов.
- `manifest.json` — версия, размер выборки, контрольные суммы и размеры двух файлов, общие характеристики покрытия. Используйте его SHA-256 для фиксации набора.

Категорию `category` задает главное намерение автора сообщения, а `workflow` описывает затронутую область. Если главного намерения нет или его нельзя установить, категория — `unknown`; при понятной области сценарий все равно указан. Цитаты, отрицания и команды в тексте размечены по контексту. Случаи с равнозначными независимыми проблемами или задачами исключены из эталонных групп.

`issue_id` обозначает наблюдаемый сбой или конкретное пожелание, а у остальных строк — случай разметки. Положительная связь возможна только у одного `issue_id` в пределах одного продукта. У каждой такой группы свой `gold_cluster_id`, одинаковый у ее участников, и `expected_signal: true`. Совпадение формулировок между продуктами не создает положительную связь. У одиночных, нецелевых и неоднозначных строк `gold_cluster_id: null` и `expected_signal: false`. Поле `case_type` задает основной срез для разбора результата; строка может сочетать несколько признаков.

До фиксации версии анализатора и его настроек не открывайте тексты и эталоны для подбора правил, подсказок или порогов. Слепота обеспечивается порядком доступа: файлы входов и эталона находятся в одном каталоге. После настройки по этому набору нужна новая независимая выборка для итоговой оценки.

Состав выборки намеренно сбалансирован по продуктам и включает трудные случаи. Частоты классов, групп и каналов не оценивают их частоты в эксплуатации. Варианты внутри групп написаны отдельно, но не являются обращениями независимых реальных пользователей. Разметка выполнена одним автором, без второго эксперта и арбитража; для неоднозначных намерений возможны альтернативные трактовки. Проверка структуры и целостности файлов не проверяет качество модели на реальных обращениях.
