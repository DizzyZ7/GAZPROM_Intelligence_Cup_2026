# Pulse Quote Search v1

Синтетические русскоязычные обращения для проверки поиска повторов по двум цитатам. Тексты, контакты и контекст продуктов придуманы для набора. Темы и тексты validation и holdout различаются. Внутри каждого сплита одна пара намеренно повторяет исходный текст в разных продуктах для проверки границы поиска.

- `*.inputs.json` содержит исходный текст и метаданные обращения. Во всех файлах записи связываются по непрозрачному идентификатору.
- `*.evidence.json` содержит подготовленные аналитиком категорию и дословные цитаты об операции и симптоме или потребности. Они подаются на вход только в режиме с подготовленными цитатами. Четыре заявки на поиск намеренно используют дословные цитаты, которые не описывают одну актуальную проблему. Для остальных случаев отказа цитаты отсутствуют.
- `*.labels.jsonl` предназначен для оценки. Общий кластер означает одну и ту же проблему или потребность в пределах продукта и категории. `expected_signal` принимает значения `repeated`, `singleton` или `abstain`. `ground_truth.must_abstain` отмечает случаи, где подходящий повтор возвращать нельзя. `ground_truth.evidence_disposition` различает уместные цитаты (`accept`), отсутствующие (`omit`) и неприемлемые (`veto`).
- `manifest.json` фиксирует объёмы и контрольные суммы файлов. Validation предназначен для настройки, holdout — для прогона после фиксации параметров.

Пары с похожими формулировками проверяют различия в операции, симптоме, категории, продукте, коде ошибки и области действия отрицания. Набор измеряет поиск при заданном режиме входных данных. Синтетический состав и размер ограничивают выводы о частоте проблем в реальных обращениях и о качестве автоматического извлечения цитат.
